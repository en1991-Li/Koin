# Koin記帳

**Koin記帳**是一款專為追求效率與視覺美感的用戶設計的記帳與財務管理工具。
透過直觀的圖表與帳戶分組功能，幫助你一目了然地掌握資產、負債與每日收支細節。

## 🚀 **核心功能**
- **帳戶總覽**：整合資產與負債數據，提供總額、資產與負債的即時數據面板。
- **動態趨勢圖表**：內建資產趨勢與分組佔比圓餅圖，視覺化呈現財務健康狀況。（尚未建立）
- **彈性的帳戶管理**：
  - 支援多種帳戶類型（現金、銀行、數位銀行、信用卡等）。
  - 信用帳戶專屬功能：可設定信用額度、繳款期限及帳單週期。
- **詳細記帳系統**：
  - 支援支出、收入、轉帳、應收/應付等多種記帳類型。
  - 內建常用商家快捷圖示（如：7-11、麥當勞、全家、Gogoro 等）。（尚未建立）
- **日曆視圖**：以日曆形式檢視每日收支，快速回顧財務軌跡。
- **專案統計**：針對特定生活開銷、投資理財、旅遊等專案進行獨立預算與支出統計。
  
## 🛠 **技術棧**
- **前端技術（Frontend)**：HTML, CSS(包含深色模式優化)
- **後端技術 (Backend)** ：使用 Node.js (Express) 建構 RESTful API。
- **資料庫** (Database)：MySQL。
- **交互邏輯**：JavaScript / ES6+
- **圖示庫**：Lucide Icons
- **版面佈局**：響應式設計 (Mobile-First)

## ⚡ **核心設計特點與技術細節**
- **單頁應用 (SPA) 視圖狀態機**：透過 showPage() 統一調度頁面層級，在切換頁面時自動清理畫面上殘留的彈窗狀態（Modal Overlays），並無縫切換底部導覽列與懸浮操作鈕（FAB）的活躍狀態。
- **單一資料來源（Single Source of Truth）與狀態同步**：建立全域 recordState 狀態物件，統一協調日期選取器、分類小卡片、計算機運算元與即時金額顯示，避免 UI 與記憶體資料脫節。
- **交易事務完整性（Transactional Balance Rollback）**：當使用者編輯或刪除既有交易時，系統會自動比對新舊金額與收支帳戶，精準執行「舊帳款回滾 $\rightarrow$ 新帳款扣除/增加」，確保總資產與負債 100% 精準。
- **子分類自動聚合機制**：透過結構化的 categoryMetaMap 字典映射，將零散的生活子項目自動映射至母分類，保持專案預算報表整潔一致。 




## 📂 **專案架構**

```text
Koin/
├── index.html          # 主頁面結構：定義 SPA 頁面容器與所有彈窗 (Modals)
├── css/
│   └── style.css       # 視覺規範：深色模式配色、Mobile-First 佈局、自定義 UI 樣式
├── js/
│   ├── script.js       # 核心引擎：處理頁面切換 (SPA)、彈窗觸發、資料 CRUD 邏輯
│   ├── projects.js     # 專案模組：專案渲染、預算統計與狀態管理邏輯
│   └── calendar.js     # 日曆模組：月曆渲染、日期計算與每日明細
├── assets/             # 靜態資源：圖示、商家 Logo 與多媒體檔案
└── README.md           # 專案文件：開發手冊與功能說明
```
